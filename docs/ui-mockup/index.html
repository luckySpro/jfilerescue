选择找回模式

两种模式都只读取源磁盘，不会向源磁盘写入任何数据。恢复出的文件必须保存到另一块磁盘。

推荐
📁指定目录找回

找回某个文件夹（及其子文件夹）中被删除的文件。通过文件系统元数据（NTFS MFT / FAT 目录项 / APFS 目录）定位，保留原文件名与目录结构，速度快。

适用：误删、清空回收站、Shift+Delete、命令行删除。

💽全盘找回

扫描整个分区或物理磁盘：先读取文件系统元数据，再逐扇区按文件签名“雕刻”。能找到格式化、分区丢失、元数据损坏后的文件，但雕刻结果没有原文件名和路径，耗时较长。

适用：格式化、分区表损坏、目录结构已被覆盖。

2
完全磁盘访问（TCC）
macOS 要求在「系统设置 → 隐私与安全性 → 完全磁盘访问」中勾选本程序，否则无法读取部分卷。授权后需要重新启动程序。
3
FileVault 加密卷
内置 APFS 卷默认启用 FileVault，原始设备读到的是密文，签名雕刻不可用；指定目录找回将通过 APFS 元数据与本地快照（Time Machine 本地快照）尝试。外置未加密磁盘不受影响。
